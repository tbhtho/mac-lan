# Guided LAN setup
User requirement: double-click one Mac host app, no Terminal or manual --listen command, discover it on Windows, explicit safe pairing and per-stream Mac consent. Preserve updater commit cfc5b632; do not touch AVE or other repositories. Mac offline: native build/run blocked, no tested-native claim.

Builder decisions: native AppKit launcher MAC-DOW Host.app starts idle; Screen Recording and optional Accessibility guidance use user-clicked system permission UI, never automatic grants. User clicks Start sharing. Go selects an up, non-loopback RFC1918 IPv4; physical interfaces precede VPN/virtual ones. UI allows alternate interface. Listener binds only selected IPv4 with OS-assigned port, never wildcard. No-interface status is actionable.

Mac NetService advertises _macdow._tcp with protocol version + ephemeral TLS SHA-256 only; never authentication tokens. Windows uses pinned MIT libp2p/zeroconf DNS-SD browser on explicit Find Mac, bounded 5-second query/results. Records untrusted, validate private IPv4/port/fingerprint/strings and deduplicate.

Guided pairing retains full native TLS certificate pinning. Windows first asks user to compare a 128-bit identity code (first 32 hex of full SHA-256) with the visible Mac screen. After confirmation Windows creates a random six-digit request number and sends pair message on pinned encrypted connection. Mac explicitly approves matching request number and actual peer IPv4 before catalog access. No unauthenticated catalog/capture/input. Pair prompts limited to three per minute, maximum 45-second response, exact unpredictable IPC request ID, stale/unknown/deny/EOF fail closed. Manual legacy token pairing remains advanced fallback, no persistent trust/credentials.

Go/UI communicate only over inherited process pipes, bounded JSON lines, no loopback control endpoint. stdout ready/error/consent/status; stdin approved request IDs/stop. Closing UI/pipe EOF or Stop closes listener + active WebSocket; lease recovery releases held input. App termination kills hung child after grace. No network activity before Start; discovery user-triggered.

Mac bundle Contents/MacOS contains AppKit launcher; Contents/Helpers contains Go host + capture. Stable bundle IDs, Info.plist local-network/Bonjour/capture purpose strings and macOS14/arm64. Native script compiles all, packages only after non-capturing self-tests. On Windows build source + Go cross-compile checks, no fake .app binary. Updater stays integrated in Windows; Mac Check updates invokes existing read-only helper, reports private-access/provenance prerequisites without gating sharing.

Acceptance: idle app clear permission status; ready shows name/identity/local endpoint; Windows Find/select/compare/pair; Mac Allow pair then Allow scoped view; Control remains explicit; app-only has no tab shell. Reserved shortcuts unchanged. No global security bypass, firewall change, credential setup, auto-capture or visible Windows test.
